# ADR 0001: Record architecture decisions

- **Status:** accepted
- **Date:** 2026-11-04
- **Phase:** 0

## Context
This is a learning project built in phases. Many choices (one database, a gateway, an offline model) look arbitrary without their reasons, and the reasons are the learning.

## Decision
Every stack choice and major trade-off gets a short ADR in `docs/adr/`, numbered in order, using `0000-template.md`. Each phase ends with at least one ADR.

## Consequences
Decisions are reviewable in PRs. Superseded ADRs stay in place and point to their replacement, so history is not lost.
